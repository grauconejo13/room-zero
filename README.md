# Room Zero

A small 3D learning experiment focused on building a room, creating original 3D assets, and placing a controllable character inside the environment.

This repository is intentionally small. The goal is to learn the basic 3D workflow by building one piece at a time rather than starting with a complete game.

## Experiment Goals

- Model a simple room and props in Blender
- Create at least one original 3D asset
- Export assets using glTF/GLB
- Import and assemble the scene in Godot
- Add an original character
- Implement basic character movement
- Add a simple third-person camera
- Experiment with lighting, materials, and shadows
- Add collision to the room and objects
- Create one small interactive moment

## First Milestone

> A character can walk around a small 3D room containing at least one object modeled from scratch.

No levels. No scoring system. No backend. No multiplayer.

Just a room, a character, and a working 3D scene.

## Planned Tools

- **Blender** — 3D modeling and asset creation
- **Godot** — scene assembly, interaction, movement, and rendering
- **GDScript / C#** — gameplay and interaction logic
- **glTF / GLB** — asset exchange between Blender and Godot

## Learning Focus

`Room Zero` is a self-education project exploring the fundamentals of a 3D asset pipeline and game-engine development.

The project will grow through small experiments rather than a fixed game design.
